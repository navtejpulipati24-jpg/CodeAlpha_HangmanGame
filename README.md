# CodeAlpha_HangmanGame

A simple text-based Hangman game built in Python as part of the CodeAlpha Python Programming Internship.

## Description
The player guesses a hidden word one letter at a time. The word is randomly
selected from a predefined list. The game ends when the player either guesses
the full word or makes 6 incorrect guesses.

## Features
- Random word selection from a predefined list
- Tracks guessed letters
- Limits incorrect guesses to 6
- Simple console-based input/output

## Concepts Used
- `random` module
- `while` loop
- `if-else` conditionals
- Strings and lists

## How to Run
```bash
python3 hangman.py
```
